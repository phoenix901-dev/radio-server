# Документация сервера интернет-радиостанции

Данный репозиторий представляет собой комплексное решение для развертывания и управления собственной интернет-радиостанцией на базе Icecast2 и MPD (Music Player Daemon). Проект включает в себя как legacy-скрипты для ручного управления, так и новый автоматизированный установщик для изоляции сред.

## Структура репозитория и назначение компонентов

### Каталог `config/`
В данном каталоге хранятся базовые конфигурационные файлы и шаблоны для настройки сервера:
* **`icecast.xml`** — основной конфигурационный файл сервера вещания Icecast. Содержит настройки портов, лимитов подключений, паролей (для источников, релеев и администратора), а также определения точек монтирования (mountpoints), таких как `/live`, `/nonstop`, `/pub` с настройками фоллбэка (fallback).
* **Каталоги `admin/` и `web/`** — содержат XSLT-шаблоны и статические ресурсы веб-интерфейса Icecast (панель администратора и публичные страницы статуса сервера).
* **Каталог `log/`** — директория, предназначенная для хранения логов сервера (`access.log`, `error.log`), если используется запуск в legacy-режиме (chroot или ручной запуск).
* **Каталог `.config/`** — директория для хранения пользовательских настроек (если применимо).

### Каталог `scripts/`
Набор legacy-скриптов для ручного управления сервером и плейлистами:
* **`installer`** — bash-скрипт для установки базовых системных зависимостей (icecast2, mpd, mpc) через `apt` с последующим отключением автозапуска служб по умолчанию.
* **`permissions`** — скрипт для автоматического исправления прав доступа (chown/chmod) для директории `/home/radio` и пользователя `radio`.
* **`service launch`** — скрипт для активации и запуска пользовательских systemd-сервисов (systemctl --user) для пользователя `radio` с включением `loginctl enable-linger`.
* **`service disable`** — скрипт для остановки и отключения системных служб icecast2 и mpd, запущенных от root.
* **`music start`** — утилита для инициализации вещания: загружает треки в плейлист MPD (mpc insert), включает случайное воспроизведение, повтор, кроссфейд 10 секунд и запускает поток.
* **`restart`** — простой скрипт для перезапуска воспроизведения в случае сбоя (`mpc play`).

### Файл `radio`
Это конфигурационный файл **crontab**, который управляет расписанием эфира. В связке с утилитой `mpc` он автоматически интегрирует в аудиопоток различные элементы:
* Вставляет отбивки времени (time announcements) каждый час (например, `efir/time/h_00o.mp3`).
* Регулярно добавляет в плейлист рекламные блоки (`efir/advertisement`).
* Вставляет джинглы станции (`efir/jingl`) на 16-й и 56-й минутах часа.
* Зацикливает и поддерживает постоянное воспроизведение основного музыкального каталога (`audio`), очищая отработанные элементы через `mpc crop` и `mpc del 1`.

## Архитектура автоматизированного установщика (`install.sh`)

Новый установщик `install.sh` предоставляет продвинутую архитектуру управления инстансами радиостанций:

1. **Строгая изоляция сред:**
   Для каждой новой станции (инстанса) создается выделенный системный пользователь без права интерактивного входа (`useradd -r -s /usr/sbin/nologin`). Это гарантирует безопасность и разграничение прав доступа между разными радиостанциями на одном сервере.
2. **Динамический менеджмент портов:**
   Скрипт содержит встроенную логику предотвращения коллизий сокетов. С помощью утилиты `ss -tln` скрипт сканирует занятые сетевые порты системы и автоматически подбирает свободные порты, начиная с `6600` для MPD и с `8000` для Icecast2.
3. **Нативные директивы Systemd для летучих путей:**
   Для управления временными файлами (PID-файлы, сокеты) и логами используются нативные механизмы Systemd: директивы `RuntimeDirectory=` и `LogsDirectory=`. При запуске службы Systemd автоматически создает необходимые директории в `/run/` и `/var/log/` с правильными правами доступа для конкретного инстанса и удаляет их после остановки.

## Руководство по эксплуатации

Для развертывания новой радиостанции с помощью автоматизированного установщика следуйте данной пошаговой инструкции. Все команды необходимо выполнять от имени суперпользователя (root).

### Шаг 1. Установка базовых зависимостей
Перед созданием станций необходимо установить системные пакеты (icecast2, mpd, mpc) и подготовить среду.
Выполните команду:
```bash
./install.sh --install-core
```
*Скрипт обновит пакетную базу, установит необходимое ПО и отключит глобальные службы по умолчанию, чтобы они не конфликтовали с будущими изолированными инстансами.*

### Шаг 2. Создание нового инстанса радиостанции
Для создания новой изолированной радиостанции используйте флаг `--create-instance` и укажите желаемое имя (например, `myradio`):
```bash
./install.sh --create-instance myradio
```
При выполнении этой команды скрипт:
1. Создаст системного пользователя `myradio`.
2. Выделит свободные порты для MPD и Icecast.
3. Создаст структуру каталогов для музыки и плейлистов в `/var/lib/radio-instances/myradio/`.
4. Сгенерирует индивидуальные конфигурационные файлы.
5. Создаст, активирует и запустит systemd-службы `mpd-myradio.service` и `icecast-myradio.service`.
В конце вывода скрипт сообщит выделенные порты для подключения.
